# 时政月度更新（101-27 形势与政策）

时政题每年考查当年度重大事件，**内容需要人工供稿**（系统不编造事件）。本目录提供"粘贴摘要 → 一条命令入库"的流水线。

## 每月流程（约 10 分钟）

1. 打开 `TEMPLATE.md`，另存为 `YYYY-MM.md`（如 `2026-11.md`）。
2. 从官方材料（人民日报、半月谈、教育部通稿等）复制当月重要事件的摘要，按模板格式整理：
   - `## 事件标题`
   - `- 要点`（每条一句话，考什么写什么）
   - 可选 `[考纲挂钩: …]`
3. 运行入库：

```bash
.venv/bin/python scripts/apply_current_affairs.py
```

4. 重生成 101 章级音频（新考点要能听）：

```bash
.venv/bin/python scripts/gen_chapter_listen.py --subject 101
```

5. 打开 App「看」页 → 思想政治理论 → 形势与政策，确认新考点已出现。

## 说明

- **幂等**：同一个月重复执行会先移除旧的 `101-27-ca*` 考点再重建，不会重复累积。
- **考点命名**：`101-27-ca01`、`ca02`…，标签自动打 `时政`、`高频`。
- **音频**：入库时该章章级听单会被清空，运行第 4 步后恢复（TTS 额度不足时会失败，额度恢复后重跑即可，已生成的片段会自动跳过）。
- **解析**：新考点如需「理解 + 考点怎么考」，运行：
  `python scripts/gen_notes.py --subject 101 --merge`
