1.4 政治“高频且基础”的知识清单

马原必会

2.3 “最基础得分点”拆解

能力层必须做到什么典型失分原因
L1 词汇常见词的核心义 + 熟词僻义 + 高频搭配只背一个中文意思；认识词但不会放进句子
L2 句法能找主干：主语、谓语、宾语、从句、非谓语一遇长句就按中文顺序硬翻
L3 阅读先找题干定位词，再判断事实/逻辑/态度凭“常识”做题，忽视原文证据
L4 翻译先拆结构，再翻逻辑，再润色中文漏主干、漏逻辑词、代词指代错
L5 小作文格式、称谓、目的、主体内容、结尾完整内容写得多但任务没完成
L6 大作文看懂图表/图画 → 描述 → 解释原因/意义 → 总结只“描述图表”，没有中心论点和逻辑展开

2.4 高频阅读考点

主旨题 标题题 细节题 推理题 词义题 作者态度题 例证题 因果/转折/对比 段落功能 指代

真正的“底层知识”不是所谓阅读技巧，而是：词汇识别 → 句子主干 → 段落中心 → 段间逻辑 → 题干与原文证据对应。英语（二）阅读占50分，因此这条链路比单独背“做题口诀”更重要。官方大纲明确将阅读和写作作为重点技能。[英语大纲：S5]

2.5 写作的基础评分点

小作文大作文
  • 对象/称谓写对
  • 任务目的明确
  • 核心信息覆盖完整
  • 结尾有收束
  • 语法、拼写、标点基本正确
  • 第一段准确描述图画/图表
  • 第二段给原因、意义或对比
  • 第三段总结或提出合理观点
  • 连接词与段落结构清楚
  • 不要追求“华丽词”，先保证正确
基础阶段最值得投入：高频词汇反复循环 + 真题长难句拆解 + 阅读证据定位 + 一套稳定的小作文框架。英语（二）总分100，但阅读+写作合计75分，天然决定了训练重点。[英语大纲：S5]
