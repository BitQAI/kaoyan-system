### 新增

- **schema 升到 `ky-point/2.0`**：
  - `cards[]` 增加 `question` / `options` / `answer` / `analysis`，保留 `front` / `back` 兼容旧前端；
  - 新增点级 `listen`（代表题 + 朗读稿 + `audio` 状态）；

- **315 题型对齐真卷**：kind 由「名词解释/简答/公式速记/综合」改为
  **选择 / 填空 / 计算 / 分析 / 合成**；每点至少 选择 + 填空。
- **812 保持官方题型**：名解 / 简答 / 论述；每点至少 名解 + 简答，第一梯队加论述。
- **101/204**：沿用原 kind，统一补 `analysis`。
- **听稿**：每点选一张代表题，拼「设问 → 答案 → 解析」；选择题把四个选项读全。
  `listen.audio` 四科均为 `pending`，本轮**不重生成音频**，`spoken` / `tts` 保持旧值。
- 新脚本：
  - `gen_cards.py`（v2 生成，四科题型 prompt + 解析一致性校验 + 断点续跑）；
  - `finalize_cards.py`（合并、赋 card_id、生成 `exam_types` / `listen`、812 配额核验）。
- 校验新增 E16–E20、W10–W14。

### 决策

  改为 prompt 要求答案位置分散 + 脚本「答案与解析字母一致性」校验。
- **音频暂不重生成**：先验收 524 点设问/答案/解析文本；音频按 `listen.script` 单独批量跑。
