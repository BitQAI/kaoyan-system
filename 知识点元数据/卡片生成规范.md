# 题型化原子卡（cards）生成规范 v3.0

> 适用：812 植物生理学（`ky-point/3.0`）。
> 315 / 101 / 204 仍按 v2.0 旧规范，待迁移。
> 目标：每张卡只考一个目标，翻面即懂，答案可自检；文字必须分段，关键处配图。

---

## 一、一张卡是什么

一张卡 = **一道按真题设问方式组织的自测题**，同时服务三个视图：

| 视图 | 消费的字段 |
|---|---|
| 记 | `question` → `answer` → `answer_points` → `analysis` |
| 看 | `kind` · `card_type` · `question` · `answer` · `answer_points` · `analysis` |
| 听 | 该点 `listen.script`（从代表卡生成） |

每张卡必须齐全：`kind` / `card_type` / `question` / `answer` / `answer_points` / `analysis` / `unit_refs`。

---

## 二、两个正交维度

### 2.1 `kind`：卷面题型（只能三选一）

| kind | 用途 |
|---|---|
| `名解` | 术语定义，正面形如「名词解释：X」 |
| `简答` | 简述 / 为什么 / 有哪些 / 比较 / 判断 |
| `论述` | 综合论证；只用于第一梯队章或确有综合价值的点，不每点标配 |

**硬性**：`kind` 只能是 `名解 / 简答 / 论述`。辨析、易错、应用、过程等**绝不能**写进 `kind`，它们属于 `card_type`。

### 2.2 `card_type`：记忆动作（九选一）

| card_type | 用途 | 典型设问 |
|---|---|---|
| `定义` | 概念、术语 | 名词解释：水势 |
| `原理` | 机制、因果 | 为什么气孔在光照下张开？ |
| `条件` | 成立条件、适用前提 | 春化作用需要哪些条件？ |
| `公式` | 公式含义、变量、适用条件 | 写出水势组成式并说明各项符号 |
| `过程` | 步骤、阶段、顺序 | C₄ 途径的三个阶段依次是什么？ |
| `辨析` | 易混概念对比 | 比较 C₃ 与 C₄ 在 CO₂ 固定上的差异 |
| `应用` | 场景判断、解题方法 | 某作物叶片萎蔫，判断是哪种水分亏缺？ |
| `易错` | 错误说法纠正 | 判断：渗透势一定为负值。错在哪里？ |
| `记忆` | 清单、分类、特征 | 植物必需元素 17 种中，大量元素有哪 6 种？ |

一张卡 = 一个 `kind` + 一个 `card_type`。例如「简答 + 辨析」「名解 + 定义」「简答 + 易错」都合法。

## 三、数量：不设硬上限

- 每点 **4 张以上**；可独立考查的 unit 各自成卡，连接性 unit 合并进同组卡。
- 每点至少 1 张 `名解`、1 张 `简答`。
- `论述` 只留给第一梯队或综合点；全科占比建议 ≤15%。
- 不为凑数拆卡；也不要把多个独立事实塞进一张卡。
- 812 试点实际：120 点 / 795 卡，每点 4–10 张，中位 7 张。

---

## 四、单卡标准（全部满足）

1. **单一考查目标**：只要求回忆一个事实、一条关系或一个判断。
2. **可独立回答**：脱离上下文仍能看懂问题并作答。
3. **答案可自检**：`answer_points` 2–6 条，每条 ≤40 字，能逐条核对。
4. **翻面即懂**：答案先给结论，解释放 `analysis`。
5. **不过度拆分**：紧密因果链、固定术语、一个公式的完整含义不机械切碎。

### 4.1 文字结构（强制）

- `answer`：先结论后要点；简答用 `①②③` 分点，**禁止一整段**。
- `answer_points`：2–6 条短句，每条只放一个判分点。
- `analysis`：**必须拆成 2–4 个短段**，每段 1–3 句；建议按「依据 / 步骤 / 易错」分段。
- 任何连续文字块不超过 **120 字**；超过必须换行或分点。
- `exam`（点级）用 `;` 分隔的短句，不写成长段。
- `keywords` 3–8 个，必须是正文中真实出现的术语；前端据此做「首次出现加粗+下划线」，
  每块最多标 8 个，避免满屏高亮。
- `listen.script` 固定「设问：… 答案：… 解析：…」三段，便于前端拆块朗读。

### 4.2 设问写法

- 名解：`名词解释：水势`。
- 简答：`简述…` / `为什么…` / `…有哪些？` / `比较…`。
- 论述：`论述…` / `试述…` / `分析…` / `请阐述…`。
- 禁止「请介绍某某知识点」这类范围过大的提问。
- 同一点内、跨点之间都不得重复设问。

### 4.3 答案与解析

- `answer`：名解 80–200 字；简答用 ①②③；论述按「立论—分论—结论」。
- `analysis`：60–400 字，写依据、步骤、易错；**不得只复述 answer**。
- 辨析卡必须点明「最关键区别」。
- 易错卡必须包含「错误说法 → 错误原因 → 正确判断」三段。
- 化学式/离子用 Unicode 角标（`C₆H₁₂O₆`、`CO₂`、`Ca²⁺`）；`SN1/SN2/E1/E2` 保持原样。

## 五、配图规则（v3.0 新增）

图的目的**只能是帮助理解知识点**，不是装饰。

### 5.1 什么时候必须配图

满足任一条件，且文字解释超过 3 句仍难建立空间/流程/对比关系时，应配 1 张图：

- **结构类**：细胞结构、膜结构、器官解剖、源-库关系。
- **流程/机制类**：水势组成、气孔运动、光合三阶段、呼吸链、韧皮部装载/卸出、酸生长、光敏色素互变、成花信号传递。
- **对比类**：C₃/C₄/CAM、冷害/冻害、旱害/涝害、主动/被动吸水。
- **因果链类**：干旱伤害、冷害膜脂相变、衰老自由基损伤。

不必配图：纯定义、纯术语、纯记忆清单、单一名解。

### 5.2 图的形式与字段

图放在**点级** `media[]`，由卡引用/继承，不重复放每张卡：

```json
{
  "kind": "diagram",
  "caption": "水势的组成与各分势符号",
  "alt": "水势等于渗透势、压力势、衬质势之和；纯水水势为 0",
  "svg": "<svg viewBox=\"0 0 640 280\" ...>...</svg>"
}
```

- `kind`：`diagram` / `formula` / `figure`。
- `caption`：必填，一句话说明图在讲什么。
- `alt`：必填，给屏幕阅读器的等效文字。
- `svg` 或 `src`：二选一；优先内联 SVG（单文件、可缩放、深浅色自适应）。
- 图内文字用中文，字号 ≥12；不得依赖颜色单独传达信息。
- 图示必须能在 375px 宽度内完整显示，不横向滚动。

### 5.3 图的生成与验收

- 图由 `subjects/812/812-media.json` 侧车维护，`build.py` 合并进 json。
- 生成后必须在 demo 的「学」「记」两视图实际渲染，检查：
  - 图注可见、不遮挡；
  - 375px 无溢出；
  - 深浅色下文字/线条可读；
  - 图与文字解释一致，不出现图中未解释的新概念。
- `validate.py` 的 `W20` 检查：图缺 `caption` / `alt` / `svg|src` 会告警。
- 补图候选用 `scripts/suggest_media.py` 评分：
  梯队(3/2/1) + 优先级(3/2/1) + 卡型(过程/辨析 3、原理 2、应用 1) + 关键词命中(≤4)；
  输出 `research/812-media-suggestions.md`。当前 120 点已配 36 图，剩余候选按分数排序，二轮继续补。

## 六、输出格式

```json
{"id":"8120202","cards":[
  {"kind":"名解","card_type":"定义","question":"名词解释：水势（Ψw）",
   "answer":"……","answer_points":["……","……"],
   "analysis":"依据：…… 步骤：…… 易错点：……","unit_refs":[1,2,3],"difficulty":2}
]}
```

- 每行一个点；`id` 必须与输入一致。
- 非选择题不要输出 `options`；812 无选择题。
- `front` / `back` 由 `finalize_cards_v3.py` 自动生成，不手写。

## 七、去重与关联

- 同科内归一化后 `question` 不得重复（E24）。
- 跨点同题必须改写为各自视角：定义归定义点，机制归机制点，应用归应用点。
- 前置关系写 `prerequisites`，易混关系写 `confusables`；不靠重复卡片建立关联。
- 812 试点曾出现 3 组跨点重复（生物/经济产量、顶端优势、光敏色素），已分别改写为「光能利用率→经济产量」「营养生长与生殖生长相关性」「成花素 FT」三张点专属卡。

## 八、常见错误

1. 把 `辨析` / `易错` / `应用` 写进 `kind` → 必须改为 `简答`/`名解`，原值放 `card_type`。
2. 一张卡塞多个独立知识点 → 拆卡。
3. `analysis` 只复述 `answer` → 重写依据/步骤/易错。
4. 简答答案一整段不分点 → 改 ①②③。
5. 长解释超过 120 字不换行 → 拆短段。
6. 机制/对比点只有文字没有图 → 补 `media` 图示。
7. 图没有 `caption` / `alt`，或图内出现正文没解释的新概念 → 补说明或删图。
8. 化学式写成 ASCII（`H2O`、`SO42-`）。
