## 3. 标签 `tags`

四个语义域，域内受控、域间可组合；每点 0–3 个。

| 域 | 取值 | 适用科目 |
|---|---|---|
| 大纲掌握层级 | `必掌握` / `理解` / `了解` | 315 |
| 命题信号 | `高频` / `常考` | 101、315 |
| 教学标记 | `基础` / `重点` / `易错` / `机制` | 812 |
| 能力项 | `词汇` / `句型` / `技巧` / `模板` | 204 |

---

## 4. 优先级 `priority`

| 值 | 含义 | 判定 |
|---|---|---|
| `★` | 高频（优先背） | `必掌握` 优先；否则 `chapter.tier==1` 或含 `{高频, 常考, 重点}` |
| `●` | 易错（额外注意） | 含 `易错` 且非 ★ |
| `○` | 普通 | 其余 |

| 值 | 含义 | 适用 |

## 6. 卡片 `kind`（卷面题型）

| 科目 | 取值 | 约束 |
|---|---|---|
| 812 | `名解` / `简答` / `论述` | 每点至少 名解+简答；tier=1 章论述≥1；全科论述 ≤15% |
| 315 | `选择` / `填空` / `计算` / `分析` / `合成` | 每点至少 选择+填空 |
| 101 | `名词解释` / `简答` / `分析` | 每点 2 张 |
| 204 | `词汇` / `句型` / `技巧` / `模板` | 每点 2 张 |

**硬性**：812 的 `kind` 只能是 `名解/简答/论述`；辨析、易错、应用等属于 `card_type`，不得写进 `kind`。

## 6.1 卡片 `card_type`（3.0 新增，812）

| 值 | 用途 |
|---|---|
| `定义` | 概念、术语 |
| `原理` | 机制、因果 |
| `条件` | 成立条件、适用前提 |
| `公式` | 公式含义、变量、适用条件 |
| `过程` | 步骤、阶段、顺序 |
| `辨析` | 易混概念对比 |
| `应用` | 场景判断、解题方法 |
| `易错` | 错误说法纠正 |
| `记忆` | 清单、分类、特征 |

`kind` 与 `card_type` 正交：同一道 `简答` 可以是 `原理`、`辨析` 或 `应用`。

---

## 6.2 证据等级 `exam_evidence.level`（3.0 新增）

| 值 | 含义 | 使用条件 |
|---|---|---|
| `verified` | 官方考纲或指定教材直接支持 | ≥1 个 syllabus/textbook 来源 |
| `inferred` | 多个可靠二手资料交叉支持 | ≥2 个独立来源，无矛盾 |
| `pending` | 仅推理或来源不足 | 必须登记 issues，不得标考频 |

---

## 6.3 溯源类型 `source.kind`（3.0 新增）

| 值 | 含义 | 校验 |
|---|---|---|
| `html` | 源 HTML 逐字抽取 | `check_locator.py` 逐字回溯 |
| `syllabus` | 官方考纲条目 | 校验考纲锚点存在 |
| `research` | Exa/教材调研 | 校验来源 id 存在 |

## 6.4 难度 `difficulty`（3.0 新增，可选）

| 值 | 含义 |
|---|---|
| `1` | 易 |
| `2` | 中 |
| `3` | 难 |

---

## 6.5 图示 `media.kind`（3.0 新增）

| 值 | 含义 |
|---|---|
| `diagram` | 机制/流程/结构示意图（优先内联 SVG） |
| `formula` | 公式/推导图 |
| `figure` | 教材裁图/外部插图 |

每条 media 必须有 `caption`（图注）与 `alt`（等效文字），且 `svg`/`src` 二选一。

## 8. 词表来源与生成规则

| 词表 | 生成方式 | 脚本 |
|---|---|---|
| 模块 | 101 按章名前缀；204 按片段标注；315 按章序边界；812 单值 | `extract.py` |
| 标签 | 812 章级下发；315 大纲层级；101 必会清单/tier 兜底 | `extract.py` + `outline_align.py` |
| 优先级 | 规则派生 | `extract.py` |
| 权重来源 | 812/315 权重报告；101 官方模块分值；204 人工值 | `extract.py` |
| 卡片 kind | 各科枚举 | `gen_cards_v3.py` / 子代理分片 |
| card_type | 生成时按知识性质选择 | `gen_cards_v3.py` / 子代理分片 |
| 证据等级 | 调研阶段按来源判定 | 人工 + `research/*.md` |
| 图示 | 关键机制/对比点人工设计 SVG | `812-media.json` |
