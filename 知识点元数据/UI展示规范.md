# UI 展示规范

> 适用：备考系统「听 / 记 / 看」三视图、Anki 式翻卡、知识点详情页。
> 目标：**易读、易扫视、易理解、易比较、易记忆**；禁止答案、解析、记忆模块首尾粘连。
> 数据来源：`ky-point/3.0` 的 `cards[]`、`answer_points[]`、`analysis`、`confusables[]`、`prerequisites[]`、`related[]`。

---

## 一、内容分区（强制）

每个知识块必须按下列顺序分区；相邻区块之间必须有可见间距或分隔线，不得首尾相连：

```
设问 / 题干
────────────
答案（先结论）
────────────
答案要点（可勾选自检）
────────────
解析（依据 / 步骤 / 易错）
────────────
关联（前置 / 易混 / 相关）
```

- 区块之间最小间距 **16px**；用分隔线时线上下各 **12px**。
- 答案区不得与解析区共用同一段文字流；解析必须另起区块。
- 答案要点用列表呈现，每条一行；不得把要点塞进一段话。

### 1.1 文本密度（强制）

- 任何连续文字块 **≤120 字**；超过必须换行、分点或拆段。
- 「考点解析」按 **2–3 句一段**拆分，禁止 300 字一整段。
- 「解析」拆 2–4 段，建议按「依据 / 步骤 / 易错」分段。
- 「怎么考」用短句列表，每条只讲一个考法/易错点。
- 简答答案用 `①②③` 分点；论述按「立论—分论—结论」。
- 列表项之间 8px，段落之间 10–12px；不得出现首尾粘连。

---

## 二、排版标尺

| 项 | 值 |
|---|---|
| 间距标尺 | 4 / 8 / 12 / 16 / 24 / 32 px |
| 正文 | 15–16px，行高 1.7 |
| 标题 | 18 / 20 / 24 / 32px，行高 1.3 |
| 辅助文字 | 13px，行高 1.5 |
| 段落间距 | 12px |
| 列表项间距 | 8px |
| 最大阅读宽度 | 72ch |
| 卡片内边距 | 20px（移动端 16px） |
| 区块圆角 | 8–12px；嵌套区块不超过 2 层 |

- 中文与英文/数字之间保留自然间距，不额外插入空格。
- 公式、化学式、上下标单独成行或置于独立区块，前后各 12px。
- 表格单元格内边距 8–12px；表格过宽时容器内横向滚动，**不得让整页横向滚动**。

---

## 三、强调规则

- 只加粗**关键词、结论、易错判断**；禁止整段加粗。
- 一屏内强调色不超过 2 种；颜色不得单独承载对错或重要性，必须配合文字、图标或边框。
- 对错色需满足 WCAG AA 对比度（正文 ≥4.5:1，大字号 ≥3:1）。
- 删除线只用于「错误说法」；不要用它删除正常内容。
- 禁止闪烁、抖动、无意义的入场动画。

---

## 四、七类模块的展示顺序

| 模块 | 展示顺序 | 要点 |
|---|---|---|
| 记忆模块 | 核心结论 → 关键词 → 公式/条件 → 补充解释 | 补充内容弱化，不喧宾夺主 |
| 看知识模块 | 核心概念 → 关键要点 → 逻辑关系 → 例子/应用 → 易错点 | 按知识类型调整顺序 |
| 答案模块 | 直接答案 → 分点依据 → 要点清单 | 答案必须一眼可定位 |
| 解析模块 | 前提 → 推导过程 → 关键判断 → 结论 | 分步骤，不写成一段 |
| 对比模块 | 对照表/并列块 → 差异高亮 → 最关键区别 | 不只靠颜色 |
| 易错点模块 | 错误认知 → 正确结论 → 判断依据 | 错误说法可加删除线/警示标记 |
| 翻卡模块 | 正面单问 → 翻面答案 → 要点 → 解析 | 解析不得淹没答案 |

---

## 五、组件规范

### 5.1 翻卡

- 正面只放 `question`，可带 `hint`；不得提前露出答案关键词。
- 翻面顺序：`answer` → `answer_points` → `analysis`；解析默认展开，超过 240 字可折叠。
- 翻面后答案区距卡片顶 16px，解析区距要点区 16px。
- 键盘：空格/回车翻卡；左右键上一张/下一张；焦点态可见。

### 5.2 对比卡

- 两列对照表，左列概念 A、右列概念 B；差异行整行浅色高亮。
- 表格下方单独一行「**最关键区别：**……」，不得省。
- 移动端列宽不足时，改为上下两块并列，不压缩成窄列。

### 5.3 易错卡

```
错误说法（删除线 / 警示色）
错误原因
正确判断（加粗结论）
```

三段之间各 8px；不要只写「错误」而不写原因。

### 5.4 步骤卡

- 编号列表 `①②③` 或 `1. 2. 3.`，每步一行。
- 步间 8px；步骤内如有多句，用分号连接，不换行。

### 5.5 关联区

- 分三组：`前置知识`、`易混淆`、`相关知识`；无内容则整组不显示。
- 每个标签为一个 chip：12px 字号、8px 内边距、圆角 999px、边框 1px。
- 易混淆 chip 必须带一句 `distinction`，可展开查看，不得只给概念名。
- 标签可点击跳转；跳转后目标点顶部高亮 1 秒。

### 5.6 选择题与填空

- 选项 A–D 各占一行，选项之间 8px；正确项在翻面后用「✓ + 文字」标记，不只靠颜色。
- 填空题空位用 `______`，长度足够点击；答案在翻面后显示，不提前占位。

### 5.7 图示

- **位置**：「学」视图放在考点解析之后、「怎么考」之前；「记」翻面放在答案要点之后、解析之前。
- **尺寸**：图示容器宽度 100%，高度按 `viewBox` 自适应；最大高度不超过视口 60%。
- **图注**：图下方 12px 处显示 `caption`，13px、辅助色、居中。
- **替代文字**：必须有 `alt`；纯装饰图不放。
- **颜色**：图内线条/文字用 `currentColor`，适配深浅色；不靠颜色单独传达对错。
- **移动端**：375px 内完整显示，不横向滚动；图内字号 ≥12px。
- **内容**：图只解释知识点，不出现正文未解释的新概念；图与文字必须一致。
- **禁止**：装饰性插图、无图注的图、需要放大才能读的密集图。

### 5.8 重点标注

- **关键词**：用 `keywords` 字段驱动，正文中首次出现时加粗 + 下划线（`text-decoration-color` 用主题色）；
  每个文字块最多标 8 个，避免满屏下划线。
- **关键句**：含「易错 / 注意 / 关键 / 核心 / 因此 / 必须 / 切记 / 区分」的段落，左侧加 3px 主题色竖线，
  不整段加粗。
- **答案要点**：用 ✓ 清单，逐条自检；不要再把要点塞回一段话。
- **禁止**：整段加粗、全文高亮、用颜色单独表达对错。

### 5.9 朗读稿

- `listen.script` 固定为「设问：… 答案：… 解析：…」三段。
- 前端必须按这三段拆成独立区块，标题用 12px 辅助色；每段内再按 2–3 句拆段。
- 禁止把整段朗读稿塞进一个 `<p>`；长稿必须可分段阅读。
- 朗读稿与卡片答案保持一致，不引入新事实。

---

## 六、数据字段映射

| 字段 | 展示位置 | 规则 |
|---|---|---|
| `kind` | 卡片角标 | 名解/简答/论述，中性色 |
| `card_type` | 卡片角标 | 定义/原理/条件/公式/过程/辨析/应用/易错/记忆 |
| `answer_points` | 答案要点区 | 可勾选清单，逐条自检 |
| `analysis` | 解析区 | 独立区块，不得并入答案 |
| `confusables` | 关联区「易混淆」 | 概念名 + 最关键区别 |
| `prerequisites` | 关联区「前置知识」 | 按 id 跳转 |
| `related` | 关联区「相关知识」 | 按 id 跳转 |
| `difficulty` | 卡片角标（可选） | 1 易 / 2 中 / 3 难 |

---

## 七、响应式

- 375px 宽度：无横向滚动、无文字截断、按钮不挤压正文。
- 1440px：内容最大宽度 1120px 居中；阅读区不超过 72ch。
- 触摸目标 ≥44×44px；相邻按钮间距 ≥8px。
- 长表格在容器内滚动，并显示「左右滑动」提示。

---

## 八、无障碍

- 语义化标题层级：页面 h1 → 模块 h2 → 卡片 h3，不跳级。
- 键盘可完成翻卡、展开解析、切换视图；焦点态对比度 ≥3:1。
- 不用颜色单独表达对错、优先级或进度。
- 动画尊重 `prefers-reduced-motion`。
- 图片/示意图必须有 `alt`；纯装饰图 `alt=""`。

---

## 九、验收清单

- [ ] 答案区、要点区、解析区、关联区各自独立，块间 ≥16px。
- [ ] 翻面先看到答案，不需要滚动才能找到结论。
- [ ] `answer_points` 以列表呈现，未塞进一段话。
- [ ] 解析没有复述答案；有依据/步骤/易错。
- [ ] 对比卡有「最关键区别」一行。
- [ ] 易错卡包含错误说法、原因、正确判断三段。
- [ ] 关联区按前置/易混/相关分组，空组不显示。
- [ ] 一屏强调色 ≤2 种，无整段加粗。
- [ ] 375px 无横向滚动、无文字截断、无按钮挤压。
- [ ] 深浅色下正文对比度 ≥4.5:1。
- [ ] 键盘可翻卡、可聚焦、焦点可见。
- [ ] 表格过宽时容器内滚动，整页不横滚。
- [ ] 公式/化学式独立区块，上下各 12px。
- [ ] 无闪烁/抖动/无意义动画。
- [ ] 所有交互都有文字或图标辅助，不只靠颜色。
- [ ] 考点解析按 2–3 句一段拆分，无 300 字整段。
- [ ] 解析分 2–4 段，简答答案用 ①②③ 分点。
- [ ] 机制/对比/流程点有图示，且有 `caption` 与 `alt`。
- [ ] 图示在 375px 内完整显示，不横向滚动。
- [ ] 图内文字/线条在深浅色下均可读。
- [ ] 关键词有加粗/下划线，每块不超过 8 个。
- [ ] 关键句有左侧强调线，没有整段加粗。
- [ ] 朗读稿按 设问/答案/解析 分块，块内再分段。
- [ ] 图示可点击放大，放大后文字可读。

---

## 十、常见反例（禁止）

1. 答案最后一句直接接解析第一句，没有分隔。
2. 解析写成一大段 300 字，没有分点/分步。
3. 整段加粗，关键词失去重点。
4. 只用红色/绿色表示对错，色弱用户无法判断。
5. 移动端卡片宽度超出屏幕，出现整页横向滚动。
6. 翻面后先看到大段解析，答案被推到屏幕外。
7. 易混概念只列名称，不写区别。
8. 关联标签不可点击，或点击后无落点高亮。
