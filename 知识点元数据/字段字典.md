### 2.1 `priority` 判定（D3）

```
1. tags 含「必掌握」 → ★
2. 否则 chapter.tier == 1 或 tags 含 {高频, 常考, 重点} → ★
3. 否则 tags 含「易错」 → ●
4. 否则 → ○
```

## 三、`source` 溯源对象

| 键 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| `kind` | 枚举 | 是 | `html` / `syllabus` / `research` | `html` |
| `ref` | 文本 | 是 | 定位符；html 精确到分句，其余为考纲/来源锚点 | `p4-2#第二章 植物的水分代谢/p[0]/split[1]` |
| `file` | 文本 | 是 | 源文件名 | `2027考研_四科知识全景与章节权重.html` |
| `section` | 文本 | 是 | 源 section 或章名 | `p4-2` |
| `basis` | 文本 | 否 | 判定依据 | `大纲条目「…」要求掌握` |
| `outline` | 文本 | 否 | 关联大纲条目定位（仅 315） | `315-01#syllabus[1]` |

- `kind=html`：`check_locator.py` 逐字回溯，必须 100% 一致。
- `kind=syllabus`：新增点来自官方考纲；校验 `research/812-syllabus.md` 锚点。
- `kind=research`：来自 Exa/教材调研；校验来源 id 存在。
- `build.py` 默认规则：`ref` 以 `syllabus:` 开头→`syllabus`；以 `research:` 开头→`research`；其余→`html`。
- 现有 116 点的 `point` 原句不得改写；确需改写时须改标 `kind=research` 并登记 issues。

## 四、`tts` 对象

| 键 | 类型 | 说明 |
|---|---|---|
| `enabled` | bool | 是否可听 |
| `max_chars` | int | 朗读段最大字符数，固定 220 |
| `est_sec` | number | 整点预估时长（秒） |
| `measured_sec` | number | 整点实测时长（秒） |
| `voice` | 对象 | 音色信息 |
| `clips[]` | 数组 | `{clip_id,text,est_sec,file?,bytes?,dur_sec?}` |

- `clip_id`：单段 = `point_id`；多段 = `{point_id}-p{n}`；与音频文件名严格一致。
- `dur_sec`：实测时长（ffprobe）；播放与进度一律用它。
- **本轮 812 音频状态**：`listen.audio=pending`，新增点无音频文件；`validate.py` 的 E15 对 pending 点放宽。

## 五、`confusables`

```json
[
  {
    "name": "水势 vs 渗透势",
    "point_id": "8120202",
    "distinction": "水势是总势（Ψw=Ψs+Ψp+Ψm）；渗透势只是溶质势分项，通常为负"
  }
]
```

- `name`：易混概念名，建议「A vs B」。
- `point_id`：可选，指向关联点；不得指向自身或不存在 id。
- `distinction`：必填，一句话写最关键区别，不写整段解释。

## 六、`exam_evidence`

```json
{
  "level": "verified",
  "basis": "2027 官方考纲第二章要求「植物细胞对水分的吸收」",
  "sources": [
    {"id": "syl-812-ch02", "title": "云南农业大学 812 考试大纲", "locator": "第二章"}
  ]
}
```

| level | 含义 | 使用条件 |
|---|---|---|
| `verified` | 官方考纲或指定教材直接支持 | ≥1 个 syllabus/textbook 来源 |
| `inferred` | 多个可靠二手资料交叉支持 | ≥2 个独立来源，且无矛盾 |
| `pending` | 仅推理或来源不足 | 必须登记 issues，不得标注考频 |

- 禁止虚构真题、考频、命题规律。
- **判定口径（可执行版本）**：见 `scripts/normalize_evidence.py::grade`。
  - `verified` 要求**条款级定位**：考纲条款 id（如 `101-syl-马1-1`）、或 basis 逐字引用条款原文、或考纲指定参考书正文。
  - **整份大纲（`syl-315` / `syl-101` / `syl-204`）不算条款级依据**——它只能证明「这门课考这些」，不能证明「这个考点对应这一条」。
  - 章节级背景 + 多来源交叉 → `inferred`；来源 <2 或不在台账 → `pending`。
- 四科现状（2026-10-28，条款级对齐落地后）：812 = 122 verified / 8 inferred；315 = 179 / 17；101 = 149 / 12（161/161 已条款级对齐）；204 = 6 / 45（51/51 已对齐，但多数条目官方只有题型结构，无考点级条款）。
- 101/204 的对齐明细在 `.build/sdd/align/out/*.jsonl`，可用 `scripts/apply_alignment.py` 重写回 md 关联表。
- `research/<sid>-sources.md` 为各科来源台账；`research/<sid>-coverage.md` 登记理解性补充 unit。

## 七、`media` 图示对象

| 键 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `kind` | 枚举 | 是 | `diagram` / `formula` / `figure` |
| `caption` | 文本 | 是 | 图注，一句话说明图在讲什么 |
| `alt` | 文本 | 是 | 屏幕阅读器等效文字 |
| `svg` | 文本 | 二选一 | 内联 SVG（优先，单文件、可缩放） |
| `src` | 文本 | 二选一 | 图片相对路径 |

示例：

```json
{
  "kind": "diagram",
  "caption": "水势的组成与各分势符号",
  "alt": "水势等于渗透势、压力势、衬质势之和；纯水水势为 0",
  "svg": "<svg viewBox=\"0 0 640 280\" ...>...</svg>"
}
```

- 图只用于帮助理解，不做装饰。
- 机制/流程/结构/对比/因果链类知识点，文字 3 句以上仍难建立关系时应配图。
- 图内文字 ≥12px；不得只靠颜色传达信息；375px 内完整显示。
- 侧车文件：`subjects/812/812-media.json`，由 `build.py` 合并进 json。

## 八、卡片字段（`cards[]`）

| 键 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `card_id` | 文本 | 是 | 全局唯一，`c{point_id}-{n}`；n 从 1 起连续 |
| `kind` | 枚举 | 是 | `名解` / `简答` / `论述`（**只能这三值**） |
| `card_type` | 枚举 | 是 | `定义/原理/条件/公式/过程/辨析/应用/易错/记忆` |
| `question` | 文本 | 是 | 完整设问；单一目标、可独立作答 |
| `options` | 数组 | 否 | 仅 `kind=选择`；812 无选择题 |
| `answer` | 文本 | 是 | 先结论后要点；简答用 ①②③ |
| `answer_points` | 字符串数组 | 是 | 2–6 条，每条 ≤40 字，用于翻面自检 |
| `analysis` | 文本 | 是 | 60–400 字；**拆 2–4 个短段**，写依据/步骤/易错；不得只复述 answer |
| `unit_refs` | 整数数组 | 是 | 覆盖的 units 1 基下标，1–3 个，不得越界 |
| `hint` | 文本 | 否 | 翻面前提示，最多一句 |
| `difficulty` | 枚举 | 否 | 1 易 / 2 中 / 3 难 |
| `front` / `back` / `point_id` | 文本 | 是 | 由 finalize 自动生成，不手写 |

### 8.1 文字结构（强制）

- 简答答案必须 `①②③` 分点；论述按「立论—分论—结论」。
- `analysis` 必须分 2–4 个短段，单段 ≤120 字。
- `exam` 必须短句列表，不写成长段。
- 任何连续文字块超过 120 字必须换行/分点。

## 九、`listen`

```json
{
  "card_id": "c8120202-2",
  "kind": "简答",
  "script": "设问：…… 答案：…… 解析：……",
  "audio": "pending"
}
```

- `card_id` 必须是该点 `cards[]` 中真实存在的一张。
- `script` 固定顺序：设问 → 答案 → 解析。
- `audio`：`ready` / `pending` / `none`；本轮 812 全量 `pending`。

## 十一、md 表格与 json 字段对应

**章节表**：`id | name | module | tier | weight_center | weight_range | weight_basis | entry_count`

**知识点表**：`id | chapter | point | title | explain | exam | keywords | priority | tags | source | spoken`

**知识点关联表**：`id | prerequisites | related | confusables | evidence`

- `prerequisites` / `related` 用 `/` 分隔 id。
- `confusables` / `evidence` 用 JSON（单元格内禁 `|`）。
- 空值写 `—`；`build.py` 按 id 合并，缺行视为空。
- `order` 不写在表里，由 `build.py` 按章内行序派生。
