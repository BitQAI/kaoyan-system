## 一、硬错误（E 码，阻断）

| 码 | 规则 | 影响 |
|---|---|---|
| `E00` | 缺少科目 json 文件 | 该科目整体不可用 |
| `E02` | `id` 格式非法 / 全局重复 / 前缀与科目不符 | 标识不可靠 |
| `E03` | `chapter` 指向不存在的章节 | 层级断裂 |
| `E04` | 必填字段为空（`point/title/explain/exam/keywords/priority/source.ref/source.file`） | 视图缺内容 |
| `E05` | 字段长度越界（`point`>120、`title`>20） | 渲染截断 |
| `E06` | `priority` ∉ {★,●,○}；`tags` ⊄ 受控词表 | 排序/筛选失效 |
| `E07` | `source.file` 为空 | 溯源断裂 |
| `E11` | 章节 `entry_count` ≠ 实际知识点数 | 计数漂移 |
| `E12` | `priority=○` 但含 `必掌握`/`重点` | 优先级矛盾 |
| `E13` | 章节 `module` ∉ 受控词表 | 层级不可用 |
| `E14` | `card_id` 缺失/重复/不符 `c{point_id}-{n}` | 卡片主键不可靠 |
| `E15` | `tts.enabled` 点：缺 `clips`、clip 缺 `file`、音频不存在、缺 `dur_sec` | 播放 404/进度错乱 |
| `E16` | 卡缺 `kind/question/answer/analysis`，或 `analysis` <30 字 | 「记」无法展示 |
| `E17` | `kind=选择` 选项不是 4 项/重复/答案非 A–D；非选择题带 `options` | 选择题不可作答 |
| `E18` | `listen.script` 为空，或 `listen.card_id` 不存在 | 「听」无法定位 |
| `E19` | `exam_types` 与 `cards[].kind` 去重集合不一致 | 「看」题型错误 |
| `E20` | 812 某章 名解<2 / 简答<2；或 `tier=1` 章 论述<1 | 章级题型配额不足 |

**E15 的 3.0 放宽**：当 `schema=ky-point/3.0` 且 `listen.audio=pending` 时，clip 缺 `file` 不报 E15；
已有 `file` 的 clip 仍校验文件存在与 `dur_sec`。

## 五、locator 回溯

`source.ref` 必须能反查到源文档同一段文字。`check_locator.py` 只对 `kind=html` 的点做逐字比对：

- 现有 116 点：**116/116 逐字一致**。
- 4 个新增点（8120215/8120216/8120309/8120606）为 `syllabus`/`research` 溯源，脚本跳过。
- 全库统计：**524/524 逐字一致（100%）**，跳过 4 点。

抽取配方（顺序不可颠倒）：

```
1. 定位 <section class="section" id="{section}">
2. 定位章名匹配的块：812 → <div class="chapter">；其余 → <h3> 起始的 topic 块
3. 取块内第一个无 class 的 <p>（排除 <p class="small"> / <p class="mech">）
4. 剥标签 → HTML 实体反转义 → 空白归一
5. 按 [；;] 切分，取第 M 片（0 基）
```

> ⚠️ 第 4 步必须先反转义再切分：`&lt;` 中的 `;` 若不先反转义，会把实体切成两半。
