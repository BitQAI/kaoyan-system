# 文档索引

本目录只放**设计与计划文档**。元数据本身的规范在 `知识点元数据/`，不在本目录。

## 目录结构与用途

| 目录 | 放什么 | 判据 |
|---|---|---|
| `specs/` | 现行设计规格：数据模型、字段口径、决策记录 | 仍在生效，或作为后续工作的依据 |
| `plans/` | 现行实施计划：按 Task 分解的执行清单 | 对应 spec 尚未全部落地 |
| `archive/` | 已被取代或被合并的历史文档 | 内容已进入更上层的文档，仅留档回溯 |

`deploy.md` 是部署与运维手册（首次部署、更新、备份、排查、回滚），不随功能迭代频繁变动。
