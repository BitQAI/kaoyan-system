# 苹果流光玻璃态 UI — 设计规格

日期：2026-10-29（v2，取代 v1 静态光晕方案）
原型：`docs/prototypes/2026-10-29-luxury-glass-v2.html`

## 1. 背景

v1 方案（静态三层光晕 + 24px 模糊）已经落地验证，但观感偏「磨砂白纸」：背景近纯色，
玻璃层后面没有可透视的流动内容，卡片只有模糊没有折光。

v2 改为两层结构：**底层是持续慢速漫游的流光背景**，**上层是定制 luxury-glass-panel**。
背景的流动让玻璃后面的颜色一直在变，材质才「活」起来。

## 2. 目标

- 全站统一：听 / 学 / 记 / 我的 / 历史 / 登录 / AI 聊天
- 浅色、深色两套完整成立（深色是烟熏玻璃，不是把白色调透明度）
- 长文对比度不下降，动效不干扰阅读
- 只动样式层与一处颜色常量，不动接口、不动数据结构

## 3. 非目标

- 不改页面信息架构、不增删功能
- 不引入前端依赖（不装 motion / tailwind / 玻璃库）
- 不碰 `知识点元数据/`（另一会话正在产出 TTS 脚本）

## 4. 材质系统

### 4.1 流光背景（`body::before`，固定层）

5 个径向渐变光斑，各自独立漫游：

| 层 | 尺寸 | 周期 | 动画 |
|---|---|---|---|
| b1 | 58vmax | 34s | drift-a |
| b2 | 52vmax | 44s（-12s 延迟） | drift-b |
| b3 | 54vmax | 52s（-28s 延迟） | drift-c |
| b4 | 46vmax | 40s（-6s 延迟） | drift-d |
| b5 | 40vmax | 60s（-34s 延迟，反向） | drift-b |

- 每个光斑 `filter: blur(48px)`、`opacity: var(--blob-alpha)`
- 动画**只改 `transform`**（`translate3d` + `scale`），配 `will-change: transform` 走合成层，
  不逐帧重算模糊
- `@media (prefers-reduced-motion: reduce)` 下全部停止

**蓝绿方案配色**：

| 层 | 浅色 | 深色 |
|---|---|---|
| b1 | #4DA3FF | #1F6BFF |
| b2 | #5AE0D0 | #00C2B2 |
| b3 | #6FE39A | #1E9E5B |
| b4 | #3BB8F0 | #1278C8 |
| b5 | #A8F0D4 | #0E7C74 |

透明度：浅色 68%，深色 60%。底色浅色 `#e6ebf5`、深色 `#04070d`。

### 4.2 颗粒层（`body::after`）

一层极淡 SVG `feTurbulence` 噪点，`opacity: .035`、`mix-blend-mode: overlay`。
没有颗粒的纯渐变会显得像塑料，这是「磨砂」质感的关键。

### 4.3 luxury-glass-panel

统一写法（层级的差别只在模糊半径与不透明度）：

```css
background:
  linear-gradient(118deg, var(--panel-sheen) 0%, transparent 34%, transparent 64%, var(--panel-sheen) 100%),
  linear-gradient(158deg, var(--panel-top) 0%, var(--panel-bottom) 100%);
border: 1px solid var(--panel-border);
box-shadow:
  inset 0 1px 0 var(--panel-inner),
  inset 0 -1px 0 rgba(255,255,255,.18),
  0 1px 2px rgba(18,28,45,.05),
  0 18px 40px -16px var(--panel-shadow),
  0 34px 90px -40px var(--panel-glow);
backdrop-filter: blur(var(--panel-blur)) saturate(190%);
```

三个层级：

| 层 | 用途 | blur | 用于 |
|---|---|---|---|
| strong | 主内容 | 40px | `.study-card` `.q-card` `.flip-front/back` `.memo-done` `.ai-chat` `.picker` `.modal-body` |
| medium | 常驻条 | 24px | `.control-bar` `.bottom-nav` `.chart-card` `.progress-strip` `.progress-panel` |
| light | 列表行 / 延伸内容 | 0（仅半透明底） | `.me-row` `.fc-row` `.sl-row` `.habit` `.history-conv` `.card-item` |

列表行不加 `backdrop-filter`：一页可能渲染几十行，逐行模糊会把低端安卓拖死。

## 6. 结构变化

### 6.1 底部导航 → 浮动 Dock

`.bottom-nav` 从通栏贴底改为浮动胶囊：

- `left:50%; transform:translateX(-50%); bottom:14px`
- `width:min(430px, calc(100vw - 28px))`，`border-radius:26px`，四边描边
- 选中项是玻璃胶囊（`inset 0 1px 0` 高光），不是实心色块
- `body` 底部留白从 64px 提到 110px，避免长内容被 Dock 压住

### 6.2 科目强调色统一

`study/page.tsx` 现在按科目覆盖 `--accent`（315 蓝 / 812 绿 / 101 红 / 204 紫）。v2 统一为蓝色，
移除 `ACCENTS` 常量与该 effect。

理由：流光背景已经是多色，再叠科目色会让整个界面失去主色；且该 effect 没有清理函数，
离开学页后 `--accent` 会残留到「我的」等页面（现存缺陷）。

### 6.3 标题层级

`.study-grid h3` 改为 `SECTION LABEL`：10.5px、`.16em` 字距、`--accent-ink`，
后接一条渐隐细线（`::after`），与正文形成明确分层。

## 7. 可访问性

- 正文 `--ink-2` 对玻璃面的对比度 ≥ 7:1
- 强调色文字统一走 `--accent-ink`，≥ 4.5:1
- 深色下不使用纯白 `#fff` 文字，用 `--ink`
- 玻璃层不透明度下限保证正文不被背景光斑干扰

## 9. 验证标准

1. `npm --prefix frontend run typecheck` 通过
2. `npm --prefix frontend run build` 通过
3. 浏览器实机：登录页、学、听、记、我的、历史、AI 聊天，浅色与深色各一遍
4. 375 / 768 / 1280 三档无布局回归，Dock 不遮挡内容
5. 关闭 `backdrop-filter`（DevTools）时回退为不透明卡片
6. 系统开启「减少动态效果」时光斑停止

## 10. 风险

| 风险 | 应对 |
|---|---|
| 多层 backdrop-filter 掉帧 | 只有 strong / medium 两层加模糊，列表行不加；模糊半径封顶 40px |
| 固定 Dock 遮挡短页面内容 | `body` 底部留白 110px，并实机检查「我的」「历史」 |
| 流光背景影响长文阅读 | 浅色光斑 α≤.68、彩虹类不采用；正文改用 `--ink-2` 深色值 |
| 移除科目色被视为功能回退 | 单点改动，一行即可恢复；已在交付说明中标注 |
| 与另一会话冲突 | 另一会话只改 `知识点元数据/scripts/`，本次不触碰 |
