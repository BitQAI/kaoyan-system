# Spec：四科知识全景合并与 812 补充

- 日期：2026-10-13
- 状态：待用户审阅
- 面向：2027 考研 云南农业大学 095400 林业（热带作物学院）
- 科目：101 政治 · 204 英语（二）· 315 化学（农）· 812 植物生理学

---

## 一、问题背景

现有 4 份独立 HTML 备考文档，内容互相重叠、风格不统一、缺乏单一检索入口：

| # | 文件 | 体量 | 定位 |
|---|------|------|------|
| 1 | `统考三科大纲知识点全景.html` | ~374KB | 官方制度、大纲原文清单、真题统计（权威层） |
| 2 | `2027考研_101政治_204英语二_315化学农_考点级大纲深度调研_V2.html` | ~76KB | 101/204/315 考点级清单、得分包 |
| 3 | `2027考研_315化学农_章节权重深度调研.html` | ~55KB | 315 章节权重推算（证据链 + 逐章卡片） |
| 4 | `2027考研_云南农业大学812植物生理学_章节权重深度调研.html` | ~42KB | 812 章节权重推算 |

缺口：**812 植物生理学（自命题，150 分）没有任何考点级内容**——只有 2 页考纲 PDF 和 4 本扫描版教材（无文字层，无法检索）。

目标：产出**单一最终 HTML**，按科目重组，纳入 812 考点级清单与四科权重数据。

## 二、方案概要

1. **按科目重构**为「总览 + 四大部分 + 附录」结构，不做拼接式堆叠。
2. **程序化切片重组**：用 Python 脚本按 h2/h3 锚点从 4 份源文件切片，按映射表重组，保证内容零丢失、不手抄。
3. **统一视觉**：采用 V2 系模板（4 份中 3 份在用：`--brand:#2457d6` 卡片风格），全景的组件做等价适配。
4. **812 新写**：绪论 + 11 章考点级清单（考纲条目 → 可背考点句 + 机制标注 + 基础/重点/易错标记），章头挂权重报告的权重中心/区间/梯队，实现"权重与知识点绑定"。
5. **权重数据**：315/812 整报告纳入对应科目（保留证据链）；101/204 沿用全景已有官方权重；总览新增四科权重速览表。
6. **源文件全部保留不动**，产出新文件 `2027考研_四科知识全景与章节权重.html`。

## 三、技术选型

| 事项 | 决策 | 理由 |
|------|------|------|
| 产出形态 | 单文件 HTML（内联 CSS/JS，`<details>` 原生折叠，零外部依赖） | 遵循项目规范，双击即用 |
| 重组方式 | Python 脚本按锚点切片重组（`.build/` 目录） | 550KB 级内容，手抄必然出错 |
| 样式基础 | V2 系 CSS + 全景组件适配层 | 3/4 源文件同模板，改动最小 |
| 导航 | 统一侧边栏 TOC（四大部分分组）+ 页内锚点，锚点 id 规则 `p<部分>-<节>` | 大文件可检索性 |
| 校验 | 脚本覆盖清单 + 浏览器实测 | 内容零丢失可证 |

不在本次选型：无构建工具、无框架、无 CDN、无需联网。

## 六、去重与保真规则

1. **权威优先**：制度/官方原文/真题统计以全景为准；可执行考点句以 V2 为准；权重数据以两份报告为准。
2. **互补合并**：同主题两侧都有的，只保留信息量更大的一方，另一方的独有行列并入（如上表"合并"项）。
3. **原文保真**：所有切片内容不做改写、不做摘要；仅允许：(a) 删除源文件内自身的页面导航/目录块，(b) 锚点 id 重编号。
4. **可信度标签原样保留**：如"官方""推论·非官方""[2026真题：S12]"等内联标注禁止改动。
5. 权重报告作为整体直取，**保留其自带的 0-10 节编号**，在 3.5/4.3 下作为子文档呈现。

## 七、812 考点级内容规范（新写部分）

- **覆盖**：绪论 + 第一章～第十一章；考纲 PDF 每个考查点均要有落点，覆盖清单按 812 权重报告的 104 条条目拆分口径逐项核对。
- **每章结构**：章头卡片（章名 + 权重中心分/区间/梯队/条目占比，取自 812 权重报告总表）→ 考点句正文。
- **考点句风格**：与 V2 附录一致——分号分隔的密排可背句（"X 的概念；Y 的特点；Z 的机制"）。
- **机制标注**：水势组成、气孔运动三学说、光合三阶段、激素作用机理、春化/光周期等机制处，补 1-2 句关键逻辑（样式：章内 `.mech` 小段）。
- **标记**：`基础`（首轮必掌握）/`重点`（高频综合）/`易错`（易混淆）三档 tag，沿用 V2 标记语义。
- **来源声明**：812 部分页脚注明"考点内容基于植物生理学通用教材共识整理，建议对照王忠、武维华教材核验；权重为推算区间，非官方"。
- **篇幅**：绪论 50-100 字；11 章每章 250-500 字考点句 + 机制标注。

## 八、视觉与导航规范

- 样式基础：315/812 权重报告的 CSS（`:root{--brand:#2457d6}` 系），并合入 V2 的 `.hero/.badge/.notice/.sidebar` 与全景的 `.lead` 多态提示框适配。
- 布局：左侧固定侧边栏 TOC（四大部分分组 + 附录），内容区卡片式 `.section`。
- 顶部 hero：标题改为四科全景，四个 badge 标注四科分值，notice 标注"权重均为推算/官方上限"。
- 锚点 id：`p0`、`p1-3`、`p3-5`、`app-a` 等；侧边栏与正文标题双向一致。
- 打印样式：沿用源文件 `@media print`（隐藏侧边栏、卡片不跨页）。

## 九、验证标准

1. **内容零丢失**：脚本输出「源 h2 章节 → 新章节」覆盖清单，逐项打勾；抽样 5 章节逐字比对（切片前后 md5 一致）。
2. **锚点**：全部侧边栏链接在页面内可跳转（抽样 ≥10 个，含四大部分/附录/3.5/4.3）；无孤儿 `href="#..."`。
3. **渲染**：浏览器实测（本地静态服务器）——表格/卡片/区间条正常；控制台 0 error；1920 与 375 宽均无横向溢出。
4. **812 覆盖**：考纲 104 条目对照清单全部有落点。
5. **源文件只读**：4 份源文件在组装前后 md5 不变。
6. **自包含**：无外部资源加载（输出中不存在指向 http(s) 的 `<link>`/`<script>`/`@import`/`url()`；来源清单里的外链文本不算）。

## 十、范围边界

**做**：合并重组 4 份文档、新写 812 考点级内容、新写 0.5 权重速览、统一样式与导航、产出单文件 HTML。

**不做**：
- OCR 4 本扫描版教材、逐字核对教材原文（成本极高，本次不引入）；
- 为 101/204 编造章节级权重（无调研报告数据，仅保留官方值）；
- 改写权重报告的结论、证据或置信度表述；
- 删除/移动/重命名任何源文件；
- 812 真题分析或得分包（无公开数据源）。

## 十一、风险与对策

| 风险 | 对策 |
|------|------|
| 812 考点内容无法与扫描教材逐字核对 | 只用多本教材共识内容；页面注明核验建议 |
