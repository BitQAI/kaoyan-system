# 进度预测：聚焦模式填充

日期：2026-10-30
状态：已选定方案，进入实施

## 1. 背景

「进度预测」图表当前用两条实线 + 两条虚线 + 低透明度区间带表达「记 / 听」的实际与预测。用户希望增加分段式面积填充：

- 实际段：当前日期之前，实际曲线到 X 轴之间用维度色低透明度渐变。
- 预测段：当前日期之后，预测曲线到 X 轴之间用琥珀色低透明度底色 + 45° 斜纹。
- 今日垂直分界线、100% 目标线、初试线保留，且不被填充遮挡。

调研结论：两条曲线都填到 X 轴会互相遮挡，并产生图例之外的混合色。用户已选择**聚焦模式**：一次只填一个维度，另一条保留为细线；另提供「双线」模式回到无填充对比。

原型：`docs/prototypes/2026-10-30-progress-fill-modes.html`。

## 2. 目标与非目标

目标：

1. 图表上方增加 `记 / 听 / 双线` 填充切换，默认「记」。
2. 聚焦维度：实际渐变填充 + 预测底色 + 斜纹，严格以今日为界分段。
3. 非聚焦维度：只保留实际细线（22% 透明度），不填充、不画预测。
4. 今日分界线、100% 目标线、初试线、曲线、圆点、tooltip 永远在填充之上。
5. 「双线」模式保持当前无填充对比视图。
6. 图例与说明随模式切换，移动端不溢出。

非目标：

- 不做小多图。
- 不改后端、不改 API、不改数据模型、不新增依赖。
- 不改 tooltip / 键盘 / 数据表的基本行为。
- 不改「完成」口径与预测算法。

## 3. 视觉规格

| 元素 | 规格 |
|---|---|
| 实际填充 | 维度色（记 `--chart-ac` / 听 `--accent`）垂直渐变：18% → 2% |
| 预测底色 | `--chart-fc` 平涂 7% |
| 预测斜纹 | `--chart-fc`，1px，45°，10×10，32% 透明度 |
| 今日分界 | `--muted` 45%，1px，`dash 3 4`，顶部「今天」小标签 |
| 100% 目标线 | `--chart-goal`，`dash 5 5`，在填充之上 |
| 初试线 | `--chart-goal`，`dash 3 4`，顶部「初试」小标签 |
| 实际线 | 2.8px 实线，维度色 |
| 预测线 | 2.2px 虚线 `6 4`，`--chart-fc` |
| 80% 区间 | 聚焦模式下改成上下两条虚线边界（28%），不做填充 |
| 所需速度 | 今日实际点到初试 100% 的细虚线（35%） |
| 非聚焦维度 | 仅实际线，22% 透明度 |
| 完成日 | 聚焦模式下在预测终点画琥珀色圆点 + `预计 MM/DD` |

层级（从下到上）：网格线 → 实际填充 → 预测底色 → 斜纹 → 100% 目标线 / 初试线 / 今日分界 → 80% 边界 / 所需速度 → 非聚焦线 → 实际/预测线 → 圆点/标签 → tooltip。

## 4. 交互

- 控件：`填充  [记] [听] [双线]`，按钮带 `aria-pressed`。
- 默认「记」。切换后立即重绘，不重新请求数据。
- 聚焦模式下，tooltip 仍显示两个维度的值；预测区间只显示聚焦维度。
- 「双线」模式：无填充、无斜纹；保留当前区间带与两条预测虚线。
- 图例：
  - 聚焦：`记/听 · 实际`、`实际填充`、`预测斜线`、`80% 区间`、`所需速度`、`初试 / 100%`。
  - 双线：沿用当前图例。
- 图表下方加一行说明：`当前填充：记；听保留为细线。切到双线可对比。`

## 5. 边界

- `insufficient / stalled / empty` 或无预测点：只画实际填充，不画预测底色、斜纹、区间边界、所需速度、完成日。
- 聚焦维度没有实际点：跳过实际填充，只画预测。
- 今日点缺失：以实际段最后一点作为接缝，预测从该点起笔。
- 移动端 375px：斜纹不糊、无横向溢出；控件可换行。
- 深色模式：斜纹与底色跟随 `--chart-fc`，不遮挡目标线/曲线。

## 6. 验证

- `npm --prefix frontend run typecheck`
- `npm --prefix frontend run build`
- 浏览器 `/me` → 进度预测：
  - 示例模式：记/听/双线切换、填充、斜纹、今日分界、目标线、tooltip、数据表。
  - 真实数据：`insufficient` 时无预测填充。
  - 375px：无横向溢出，斜纹可辨。
  - 深色模式：颜色与对比正常。
- 控制台无报错。

## 7. 风险

- 斜纹在 375px 下可能偏密；必要时把 pattern 从 10 调到 12。
- 深色模式下琥珀色斜纹可能偏暗；必要时提高透明度到 0.42。
- 预测区间带改成边界线后，不确定性表达弱于填色；tooltip 与图例仍需保留区间信息。
