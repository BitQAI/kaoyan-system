# 作文版式、答案排版与笔记入口精简

日期：2026-10-30
状态：实施中

## 1. 背景

1. **笔记占空间**：每张卡下方常驻「我的笔记」区块，属于低频功能，却挤占听/记的主要阅读区域。
2. **翻面冗余**：「记」翻面后还有「读释义」按钮，与整体播放重复。
3. **作文版式塌陷**：204 写作卡片的 `answer` 是纯英文文本，前端 `paragraphs()` 只按中文句号切段，整篇作文被渲染成一整块；范文自带的段意（目的句/理由展开/收尾）与好词好句（`keys`）没有进入卡片数据，信件缺称呼、正文、落款分区；315/812 的「解析」也是整段纯文本直接塞进 `.prose`，换行信息丢失。
4. **词数不达标**：小作文 67–83 词、大作文 88–115 词，低于 100 / 150 的要求。

## 2. 目标与非目标

目标：

1. 听、记两处的笔记改为顶部工具条上的「笔记」标识（与「收藏」并列）：有笔记时高亮，点击打开弹窗编辑；卡片正文不再为笔记留任何占位。
2. 去掉「记」翻面后的「读释义」。
3. 作文卡：
   - 范文补足到小作文 ≥100 词、大作文 ≥150 词，构建脚本硬校验；
   - 卡片带结构化的 `essay` payload（考试类型、格式、段落角色、中英对照、好词好句、词数）；
   - 信件呈现称呼、正文三段、落款右对齐；通知呈现标题、正文、日期；图表作文按「描述/原因/结论」分段；
   - 好词好句高亮，段落带角色标签，显示词数与要求；
   - 听、记两个模块都用这套版式。
4. 通用答案/解析排版：保留原文换行，按句成段，关键句（易错/注意/因此…）左侧强调线；解析不再是一坨纯文本。

非目标：

- 不重新生成作文音频（仍走 TTS 回退）。
- 不改调度、队列排序、笔记表结构。
- 不重写词卡/词组卡/辨析卡与完形填空的既有版式。

## 3. 数据

### 3.1 范文扩写（`204-essays.jsonl`，唯一事实源）

- 仅在各段末尾追加新句子，**不改动既有句子**，保证 `blanks` 挖空仍能匹配。
- 目标：`204-08` 小作文 ≥100 词、`204-09` 大作文 ≥150 词，留 5–15 词余量。
- 中文译文同步补齐。

### 3.2 构建（`scripts/essay_build.py`）

- 为卡片生成 payload：

```json
{
  "type": "essay",
  "format": "letter | notice | chart",
  "exam": "小作文 | 大作文",
  "title": "...",
  "scope": "full | paragraph",
  "index": 1, "total": 3,
  "word_count": 108,
  "min_words": 100,
  "paragraphs": [{"role": "目的句", "en": "...", "cn": "...", "keys": ["..."]}]
}
```

- 模板卡 `scope=full`（全部段落）；回译/默写卡 `scope=paragraph`（当前段）。
- 构建时校验整篇词数，低于下限直接失败并打印篇目。
- 之后依次跑 `vocab_assemble.py` 生成 204.json，再导入应用。

## 4. 前端

### 4.1 笔记入口

- `CardNote.tsx` 改为 `NoteDialog`：遮罩 + 面板，textarea + 保存 + 关闭，⌘/Ctrl+Enter 保存，空内容即删除。
- 听/记顶部工具条加「笔记」按钮：当前卡有笔记时高亮（`.on`）。
- 删除卡片正文里的笔记区块与相关样式。

### 4.2 作文版式（`EssayFace.tsx`）

- 元信息行：`小作文/大作文` 徽标 + `108 词 · 要求 ≥100`（达标绿色，不足琥珀）。
- letter：首段拆出称呼行；末段拆出落款块右对齐；其余按段渲染。
- notice：首行 `Notice` 作标题；末尾日期右对齐。
- 每段：角色小标签 + 英文正文（好词好句 `<mark>`）+ 中文译文（弱化）。
- 单段卡额外显示「第 i/3 段」。

### 4.3 通用排版

- `paragraphs()`：先按换行切块，再在块内按中文句号每 2 句成段；英文段落保持整段。
- 「记」的解析改用 `paragraphs()` 渲染。
- 样式：段落间距、关键词 `<mark>`、强调线沿用现有变量。

## 5. 影响范围

- 数据：`204-essays.jsonl`、`scripts/essay_build.py`、生成物 `204-essay-points.json` / `204.json`
- 前端：`CardNote.tsx`、`ListenView.tsx`、`MemoView.tsx`、`WordFace.tsx`、`EssayFace.tsx`（新）、`lib/types.ts`、`lib/listen-player.ts`、`lib/render.ts`、`globals.css`
- 不改后端表结构、不改迁移
