## Task 1 · 令牌层与背景层

**文件**：`frontend/src/app/globals.css`

- [ ] 重写 `:root` 令牌块：`--ink` `--ink-2` `--muted` `--line` `--accent*` `--good/warn/bad`
      `--panel-*` `--bg` `--blob-*` `--blob-alpha` `--radius-xl/lg/sm`
- [ ] 重写 `html[data-theme="dark"]` 块：烟熏玻璃面板令牌 + 单独覆盖 `--accent` 三件套
- [ ] `body` 改为 `background:var(--bg)`，`padding-bottom:110px`
- [ ] 新增 `body::before` 流光层：5 个 `.blob` 等价物用 `background` 的多层 radial-gradient +
      伪元素动画不可行 → 改为在 `layout.tsx` 插入 `<div class="aurora">` 容器与 5 个 span
- [ ] 新增 `body::after` 颗粒层（SVG feTurbulence data URI）
- [ ] 新增 `@keyframes drift-a/b/c/d`
- [ ] 新增 `@media (prefers-reduced-motion: reduce)` 停止动画

> 注意：`body::before/after` 只能承载一层背景，多个独立漫游的光斑必须用真实元素。
> 因此在 `layout.tsx` 的 `<body>` 内插入 `<div class="aurora">`（5 个 span）与 `<div class="grain">`。

**验收**：本地起 dev server，任意空白页可见背景缓慢流动。

## 风险与应对

| 风险 | 应对 |
|---|---|
| `body::before` 无法承载多光斑 | 用真实 DOM 容器（Task 1） |
| 底部留白不足导致 Dock 遮内容 | Task 6 逐页检查 375 宽 |
| 列表行模糊拖慢渲染 | `.glass-row` 不加 backdrop-filter |
| 旧 CSS 硬编码色残留 | Task 3 全局 grep `rgba(127,127,127` 与 `#` 字面量 |
