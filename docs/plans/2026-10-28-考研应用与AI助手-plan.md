## 风险与回退

| 风险 | 触发信号 | 回退 |
|---|---|---|
| Next rewrites 代理 SSE 卡顿 | 首字延迟 > 5s 或一次性吐出 | 改用 `app/api/assistant/ask/route.ts` 显式代理（`runtime='nodejs'`，pipe ReadableStream） |
| Alembic 与手写 DDL 漂移 | `alembic check` 报差异 | 以迁移为准重建表；补 DDL 一致性测试 |
| 上下文过长导致回答慢 | 首字 > 10s | 先砍 L3 召回数量 5→3，再砍 units |
| 原型样式迁移后走形 | 与 demo 对比明显不一致 | 直接 `<iframe>` 对照，逐块比对；必要时搬原型 CSS 原文 |

### 实施中修掉的两个真问题

1. **SSE 被误判中断**：`request.is_disconnected()` 在 `StreamingResponse` 里会误报 True，导致回答在 312 字处被标记 `truncated=1`。改为只在 `CancelledError / GeneratorExit` 时记中断。
2. **历史按点反查为空**：`message_points` 只挂了 assistant 消息，而查询按 user 消息过滤。改为问答两行都挂知识点。
