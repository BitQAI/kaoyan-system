## Task 1 后端音频路由

- [x] `config.py`：`AUDIO_DIR = Path(os.getenv("KY_AUDIO_DIR", str(DATA_DIR / "audio")))`
- [x] `routers/audio.py`：
  - `GET /api/audio/{card_id}` → 查 `card → point.subject_id`，拼路径，存在返回 `FileResponse`，否则 404
  - card_id 做白名单校验（`^c[0-9]{6,8}-[0-9]+$`），避免路径穿越
  - `Cache-Control: private, max-age=604800`
- [x] `main.py` 注册
- [x] `tests/test_audio.py`：造一个临时 mp3（1KB 假字节）断言 200 + content-type；不存在的卡 404；未带 token 401
- [x] 跑 `pytest tests -q`

## Task 2 前端播放

- [x] `lib/listen.ts`：
  - `loadAudio(cardId): Promise<string>` — fetch（带 `authHeaders`）→ blob → objectURL，失败抛错
  - `readRate()` / `writeRate()` — localStorage，clamp 0.6–3.0，默认 1.5
- [x] `ListenView.tsx`：
  - `audioRef`（单例 `new Audio()`），`urlRef` 记录当前 blob
  - `play(target)`：先 `stopTTS()`，`loadAudio` → `audio.src` → `playbackRate = rate` → `play()`
  - `audio.onended` → 复用现有记账 + 连播逻辑
  - `audio.onerror` / `loadAudio` 失败 → `speak(target)` 回退
  - `stop()` 同时停 audio 并清 blob
  - MediaSession 的 play/pause 改绑 audio（回退态仍走 TTS）
  - 预取：当前段开播后 `loadAudio(next.card_id)` 预热缓存

## Task 3 语速

- [x] 滑块 `RATE_MAX` 1.6 → 3.0，默认 1.5，从 `readRate()` 初始化
- [x] `onChange` 时同时 `writeRate` 并设置 `audio.playbackRate`（播放中立即生效）
